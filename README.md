# fitSphere

A sports learning, training and coaching platform. v1 covers Boxing, Strength & Conditioning, and Gym & Fitness, for adults in India.

## Status
Building. Setup milestone S0 is nearly done. See the build board: `docs/plans/board.json`.

## Run it
```
npm ci
npm run dev      # web app
npm run verify   # typecheck, lint, tests, build
npm run db:start # local Supabase, needs Docker
npm run test:db  # database tests
```
