M6 launch plan

Merged from my draft, a Codex review and a Fable planner review. Each finding below was checked in the repo on 21 Nov 2026.

What the reviews found that changes the plan

  • Real users cannot sign in yet. The release gate in TASKS.md needs our own email sender (SMTP), Turnstile, the site URL and a redirect allow-list. The built-in Supabase mailer is for testing only. So even a beta needs a domain and Resend.
  • Hiring and chat are live in production. Only payment is closed. People can send requests and messages, and there is no way to report abuse. The beta must close both.
  • The live home page is a placeholder. It shows "App scaffold is running".
  • There is no 404 page, no error page and no app manifest. No security headers are set. /styleguide is public.
  • Previews write to the production database, and the free plan has no backups.
  • The privacy draft leaves out hiring, messages, payments, the AI provider abroad, a grievance contact, retention and children.

Top risks

  • Real users' health data with no signed privacy notice. The lawyer gate before 1b covers it.
  • Data loss: no backups, and previews write to production. M6-07 and M6-12 cover it.
  • An empty beta: the library still holds sample content. M6-13 and your founding coaches cover it.
